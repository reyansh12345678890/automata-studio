Formal machine definition

The mathematical representation of the selected machine.

M = (Q, Σ, Γ, δ, λ, q₀)
Q — States {E, O}
Σ — Input alphabet {0, 1}
Γ — Output alphabet {0, 1}
q₀ — Initial state E
Transition function (δ) δ(E,0)=E · δ(E,1)=O δ(O,0)=O · δ(O,1)=E
Output function (λ) — Mealy
λ(E,0)=0 · λ(E,1)=1 λ(O,0)=1 · λ(O,1)=0
The machine tracks whether the number of 1s read so far is even or odd.
